# RAIN POKER PUB

모바일 우선 홀덤펍 타이쿤 웹게임.

## v0.1 원칙

이 저장소는 목업 전용 프로젝트가 아닙니다. 화면에 완성 기능처럼 표시되는 행동은 실제 게임 상태와 연결되어야 합니다.

첫 플레이 목표:

1. 실제 계정 생성 / 로그인
2. 계정별 서버 세이브 생성
3. 빈 첫 매장 진입
4. 건설 메뉴에서 기본 포커 테이블 1개 실제 배치
5. 직원 > 딜러 > 기본 모집에서 일반 딜러 1명 실제 모집
6. 딜러를 테이블에 실제 배치
7. 영업 시작
8. 1주차 월요일부터 시간 진행
9. 실제 손님 생성 → 입장 → 좌석 이동
10. 자동 저장 후 재로그인 시 이어하기

## 첫 매장 공간 기준

기본 포커 테이블의 최소 운영 모듈은 아래 개념을 기준으로 합니다.

- ㅁ: 통로/빈 바닥
- ㅅ: 손님 1명 점유 칸
- ㄷ: 딜러 1명 점유 칸
- ㅌ: 테이블 본체 점유 칸

```text
ㅁㅁㅁㅁㅁㅁㅁ
ㅁㅁㅅㄷㅅㅁㅁ
ㅁㅅㅌㅌㅌㅅㅁ
ㅁㅅㅅㅅㅅㅅㅁ
```

첫 매장은 최대 4개 풀 테이블과 별도 편의시설/소파 영역을 수용할 수 있도록 설계합니다.

## 직원 v0.1

- 직군: 딜러 / 서빙
- 활성 모집: 기본 모집
- 기본 모집 결과: 일반 딜러
- 가챠/특별 모집은 후속 버전
- 서빙 직군은 데이터 구조를 분리하되 실제 모집 기능이 생기기 전에는 작동하는 것처럼 표시하지 않습니다.

## 인증/저장

실제 계정과 클라우드 세이브는 Supabase Auth + Database 연결을 목표로 합니다.

브라우저 코드에는 공개 가능한 anon key만 사용하며, `service_role` 키나 비밀번호 같은 비밀값은 커밋하지 않습니다. Row Level Security로 각 사용자가 자신의 세이브만 읽고 쓰도록 설정합니다.
